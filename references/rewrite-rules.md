# 改写规则与自检

## 一、量化指标

| 指标 | 轻档 | 中档 | 爆档 |
|---|---|---|---|
| 平均句长 | ≤ 25 字 | ≤ 15 字 | ≤ 10 字 |
| 最长句 | 35 字 | 25 字 | 15 字 |
| 感叹号频率 | 每 3 句 1 个 | 每 2 句 1 个 | 每句最多 1 个 |
| 段落行数 | ≤ 3 | ≤ 2 | 1 |
| 三连排比组数 | 0~1 | 1~2 | 2~3 |
| emoji | 0 | 0~2 | 1~3 |
| 问句 | 允许 | 少用 | 基本不用 |

**断句手法**（句子太长时按此顺序拆）：

1. 在"但是/所以/因为/如果"前断开，连接词删掉
2. 把"的"字定语拎成独立短句
3. 名词化动词还原：进行优化 → 改好；实现提升 → 提上去
4. 拆不动的，直接砍掉修饰

**标点**：

- 少用分号、破折号、括号。括号里的补充内容要么提上来当一句，要么删。
- 冒号只在"结论：xxx"或清单引导时用。
- 句号改感叹号要克制：强调动作或判断时才换，陈述事实保留句号。

## 二、人称与视角

- 主语用"你"，不用"用户/读者/大家/我们"。
- 讲方法用"我"：我给你、我建议、我踩过。第一人称能拉近距离，但**只能用于真实经验**，不能编。
- 不用"作为一名……"，直接开口说事。

## 三、术语替换表

| 原词 | 换成 |
|---|---|
| 进行/开展 | 做 |
| 实现/达成 | 做到、搞定 |
| 基于 | 按、用 |
| 通过（手段） | 用、靠 |
| 涉及 | 关系到、牵扯到 |
| 优化 | 调好、改顺 |
| 提升/增强 | 提上去、加上去 |
| 赋能 | 帮上忙、给力 |
| 闭环 | 走完一圈、有回音 |
| 抓手 | 下手的地方 |
| 维度/层面 | 角度、方面 |
| 机制 | 怎么运转的、规则 |
| 策略/路径 | 办法、走法 |
| 助力/打造/构建 | 帮、做、搭 |
| 显著/有效 | 真的有变化、挺管用 |
| 进一步 | 再 |
| 相关/一定程度上 | 删掉，或说"有些" |
| 综上所述 | 就这些、说白了 |
| 建议您 | 你就 |
| 需注意 | 注意、记着 |

**专业内容例外**：术语是信息本体时不能换（碱度、烧结终点、料层厚度、FeO）。只把它周围的官话拆掉，术语本身留着，紧跟一句大白话解释。

例：
> 原：需结合碱度要求对熔剂配比进行优化调整。
> 改：碱度定下来，熔剂就按这个数配。差一点没事，别差太多。

## 四、四种结构模板

**A. 三段式（通用）**

```
定心丸一句
→ 结论一句
→ 三连要点（3 个短句）
→ 推一把一句
```

**B. 清单式（教程/干货）**

```
别慌，就 3 步。
1. 动作 + 结果
2. 动作 + 结果
3. 动作 + 结果
照着做，出不了岔子。
```

**C. 口播式（短视频/直播）**

```
钩子：你是不是也遇到过……（或：说个反常识的）
共鸣：我第一次也这样。
给货：其实就一句话——
收尾：记住这句，今天就够用了。
```

**D. 情绪式（安慰/夸夸）**

```
接住：我知道你现在……
命名：你不是 X，你是 Y。
给价值：你能做到 Z，说明……
小步：今晚只做一件事：……
```

## 五、去味反向操作

用户说"太油了""改回正常说法"时执行：

1. 删所有感叹号，改句号
2. 三连排比压成一句陈述
3. "别慌/放心/就按我说的"等指令式开头全删
4. 短句合并回正常长度（20~35 字）
5. 口语词换书面词（搞 → 处理，弄 → 调整，整 → 做）
6. 结构恢复为"背景—做法—结论"，可加小标题
7. 保留事实，只削语气

去味后不要残留"说白了""一句话""就这么简单"这类口头衔接词。

## 六、交付前自检

逐条过，任一不过就改：

- [ ] 首句是定心丸或结论，不是背景铺垫
- [ ] 平均句长达标，没有超过上限的长句
- [ ] 至少 1 组三连排比，且不重复用同一个词
- [ ] 术语已清或已配大白话解释
- [ ] 只给了一个方案，没有"可以 A 也可以 B"
- [ ] 结尾是动作，不是"希望对你有帮助"
- [ ] 没有虚构个人经历或效果承诺
- [ ] 涉及钱/健康/法律/安全时，"绝对"类表述已降级
