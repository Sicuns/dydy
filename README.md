# dydy · 豆言豆语

把一个正经句子，改成豆包味儿。

> 短句、排比、波浪号、先共情再给结论。主打情绪价值，最后一句一定是"就这么干"。

一个中文文案改写 Skill。装进 WorkBuddy / Claude Code 之后，说一句"豆包味改写"，它就把你的话翻成这个调：

```
宝子~我太懂你这种感觉了！
最直白、最不绕弯、最戳心窝子的结论就一句：
不是你不行，是学习早被改成了换饭吃的活儿~
你把它当工具，它也把你当工具，谁也不亲谁。
你疼的不是脑子，是天天硬逼自己坐下的那口气。
能坐下，你已经够狠了，别骂自己没毅力~
今天只干一件：查个你真想知道的问题，不为用，就为爽！
那半小时，学习才是你的~
```

## 这是什么

不是"多加几个感叹号"。豆包味的内核是**替读者把犹豫、计算、判断全部接管掉**，让他只需要点头，然后照做。

拆开来是五件事：

| # | 动作 | 说明 |
|---|---|---|
| 1 | 抽结论 | 把原文压成一句话的动作 |
| 2 | 拆短句 | 单句不超过 15 字，超了就断 |
| 3 | 加定心丸 | 首句先卸掉"我可能做不好"的负担 |
| 4 | 配三连 | 每个核心观点配一组同构排比 |
| 5 | 推一把 | 结尾给确定性动作，不给选择题 |

## 五档语气

同一段话，五种用法。改写前先定档，用户没说就按内容判断。

| 档位 | 代号 | 用途 | 情绪主轴 |
|---|---|---|---|
| 治愈鸡汤 | T | 安慰、陪伴、低谷期 | 你不孤单，慢慢来也行 |
| 干货催促 | G | 教程、清单、带货口播 | 别想了，照做，包会 |
| 夸夸自信 | P | 鼓励、复盘、打气 | 你已经很对了，再加一点 |
| 白话翻译 | W | 专业内容降门槛 | 这事没那么玄，我说人话 |
| 温柔拒绝 | R | 婉拒、催款、坏消息 | 不是你的问题，我陪你解决 |

味度另设三档：**轻**（只换语气）/ **中**（句长腰斩）/ **爆**（全短句口号化，可上波浪号和 emoji）。

## 用法

```
豆包味改写：<你的原话>
```

触发词（说任意一个都会命中）：

`豆包味` `豆包风` `情绪价值` `整点鸡汤` `安慰一下` `鼓励鼓励` `说得温柔点` `说人话` `小白版` `口播稿` `照着做就行`

反向也支持：

```
太油了，去味        → 还原成中性书面语
```

## 三个例子

### 1. 专业内容降门槛（W 档）

**原话**

> 烧结配矿需先完成化学成分分析，再依据碱度要求配加熔剂，最后校核冶金性能。

**改写**

> 别被"配矿"俩字唬住，就三步。
> 先测成分，知道手里是什么料。
> 再按碱度配熔剂，该加多少加多少。
> 最后校核性能，看烧结能不能跑顺。
> 不用记原理，顺序别换就行。

### 2. 安慰（T 档）

**原话**

> 这次面试没过，有点难受。

**改写**

> 没过就没过，先别急着怪自己。
> 一场面试定不了你这个人，它只说明这次不合适。
> 你今天能走进那个房间，已经比很多人强了。
> 今晚别复盘，好好睡一觉。明天再说下一步，我陪你捋。

### 3. 去味（反向）

**原话**

> 别慌！我给你讲得清清楚楚、明明白白、一点不费劲！就按我说的做！

**还原**

> 做法不复杂，按以下步骤执行即可。

## 豆言豆语从哪来

这个 Skill 的一半素材，是从网上真实流传的豆包句式里收的，都标了出处：

- **「（后略）的结论」** —— 豆包解释问题时的开场白，排比堆到三十个「最」，最后的答案常常是「我不知道」。梗就笑在这个反差上。出处：[萌娘百科 · AI梗](https://mzh.moegirl.org.cn/zh-cn/AI梗)
- **共情四步** —— 先共情 → 再肯定 → 用「不是 A，而是 B」转折 → 用「我就在这里」收尾。这是所有大模型被 RLHF 调出来的同一套模板。
- **哄人原句** —— 短视频里真实的豆包回复，把无数老人听哭的那批。不靠排比，靠具体的体贴：「想哭就哭两声，想骂就骂两句，我就在这听你说」。
- **豆包型人格** —— 「惹到我，你算是踢到棉花了」「对对对，你说的都对」。只用于自嘲，别拿去糊弄工作。

原句辑录见 [`references/doubao-isms.md`](references/doubao-isms.md)，按 **可直接用 / 慎用 / 别用** 三级标注。

## 三条红线

玩梗可以，别玩脱。以下三条优先级高于任何语气要求：

1. **排比不能替代结论。** 原梗的笑点就是"堆三十个最，答案是我不知道"。真拿去做文案，排比完必须给实质内容，否则就是废话文学。
2. **「对对对」不能替代判断。** 无条件顺从是豆包被吐槽最多的毛病。可以有温度，但结论必须真。
3. **共情的力量来自具体。** 「稳稳接住你」能哄哭人，不是因为"接住"这个词，是因为它说了"想哭就哭两声"。抄词不抄具体，立刻变工业糖精。

另外，涉及钱、健康、法律、安全的场景，「绝对不出错」会自动降级成「按这个思路走，出错概率更低」。不虚构「亲测有效」这类经历。
